# belgian-football-corners-cards-edge

Grok skill for generating high-edge singles and ACCAs focused on corners (hoekschoppen) and yellow cards (gele kaarten) in Belgian Pro League and Super Cup matches.

## Install

```bash
bash /root/.grok/skills/skill-installer/scripts/install-skill.sh --url https://github.com/Stijnman/belgian-football-corners-cards-edge
```

Or clone and place the folder under `.grok/skills/`.

## Triggers
- Brugge vs Union tips
- hoekschoppen / corners Belgian
- gele kaarten / yellow cards Super Cup
- Belgian football over corners cards ACCA
